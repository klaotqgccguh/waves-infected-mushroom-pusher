## Overview

Waves Infected Mushroom Pusher is a multiband saturation and dynamics processor designed by Infected Mushroom for adding loudness, punch, and psychedelic color to tracks and mixes.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Waves Infected Mushroom Pusher** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Multiband Saturation** | Independent saturation per band with harmonic enhancement |
| **Psychedelic Mode** | Extreme saturation setting inspired by Infected Mushroom productions |
| **Punch Mode** | Transient enhancement and dynamic punch per frequency band |
| **Output Limiting** | Built-in output limiter prevents clipping after heavy processing |
